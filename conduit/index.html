Network File Browser: Conduit

Support and frequently asked questions.

Need help? Get in touch through signex.ai/contact and mention Conduit. We read everything.

Which protocols does it support?

WebDAV and FTP/FTPS in full — listing, streaming, preview, upload, download, rename, move, delete and new folder. SMB and SFTP are not supported: iOS provides no system API for either transport, and we chose not to ship a half-trusted third-party implementation on a path that carries your credentials. The connection editor says so plainly rather than hiding the options.

Can I connect to my NAS?

If it speaks WebDAV or FTP, yes — most NAS units, routers with USB disks, Nextcloud and ordinary web hosts can enable one of the two. Look for "WebDAV" or "FTP service" in the device's own settings, then add the address in Conduit.

Where is my password kept?

In the iOS Keychain, the system's encrypted credential store — never in the app's own files. It is sent only to the server you typed in, and deleting a connection deletes its password from the Keychain too.

Why does iOS ask about the local network?

Reaching a NAS or router on your home network requires the local-network permission. iOS shows that prompt on Conduit's first connection attempt; decline it and local servers become unreachable, though servers on the internet still work.

Can I stream a film without downloading it?

Yes. Media plays directly from the server in the built-in player, and documents open in preview without a permanent download.

What happens to a transfer if I leave the app?

Transfers continue in the background where the protocol allows it, and Conduit remembers in-flight transfers — a file that finishes arriving after the app was closed is filed, not lost. One quirk to know: in the queue, failed transfers currently sort below completed ones, so scroll down to find a failure.

My FTP listing looks wrong or empty

Conduit asks the server for a machine-readable listing first and falls back to parsing the classic Unix and DOS formats. If your server emits something rarer, get in touch with the server model and we will look at it.
